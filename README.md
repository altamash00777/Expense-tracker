<h1>Expense Tracker Web App</h1>

This is a simple Expense Tracker built using **HTML, CSS, and Vanilla JavaScript**.

<h2>Features</h2>
<p>- Stores expense data using **Local Storage**, so no database is required</p>br
<p>- Data remains saved even after refreshing the webpage</p>br
<p>- Local Storage can store approximately **5MB–8MB of data** in the browser</p>br
<p>- Tracks expenses with **current date and time** using JavaScript Date functions</p>br
<p>- Clean and user-friendly interface</p>br

<h2>Tech Stack</h2>
- HTML
- CSS
- JavaScript (Vanilla JS)
